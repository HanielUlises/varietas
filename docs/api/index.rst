API reference

templated, and a Doxygen dump of the signatures would say less about it than the
constructions in :doc:`../theory/index` do; what follows is the public surface
grouped by what it is for, with the templates written as they are meant to be
called.

Every name is in namespace ``varietas`` unless stated otherwise.
